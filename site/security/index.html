envit security

What envit contacts, what it writes, how releases are verified.

Network

envit contacts only the git remotes that your manifests declare. It fetches over the plain git protocol (HTTPS, or file://) with an embedded git implementation. It sends no telemetry, checks for no updates, opens no ports, and calls no forge API.

requestwhen
git fetch to a declared remotesync for a repo or skill with no usable checkout in the store, or a stale auto repo (at most once per 24 h), or update
nothingsync --offline, sync --frozen with a warm store, status, skills, pin, gc

Set ENVIT_NO_REFRESH=1 to block every implicit fetch. sync --offline guarantees no network for one run.

envit never modifies files inside a checkout, never creates AGENTS.md or CLAUDE.md, and never deletes a symlink or directory it did not create.

Skills are instructions

A skill is text that an agent will follow. Treat a skills source like a dependency with the ability to run code. envit gives you three controls:

  • Pinned. Every skill is materialized at the commit recorded in envit.lock.json. It cannot change between syncs. Only update moves it, and update prints the old and new commits.
  • Reproducible. sync --frozen installs exactly the reviewed commits, on any machine, or fails.
  • Selective. You name each skill you take from a source. Nothing else from that repo lands where agents look.

Review a skills source before you add it. Pin it with "update": "frozen" if you want no drift at all.

Release integrity

Release binaries are built by the public workflow in .github/workflows/release.yml from a version tag. Each asset ships with a SHA-256 checksum and a GitHub build-provenance attestation. The install script verifies the checksum, and verifies provenance when the GitHub CLI is available. Verify by hand:

gh attestation verify envit-aarch64-apple-darwin.tar.gz --owner plannotator

The source is Rust with #![forbid(unsafe_code)] in both crates. Continuous integration runs clippy with warnings as errors, the full test suite on macOS and Linux, and cargo deny for advisories, licenses, and sources. Actions are pinned by commit SHA. Dependabot watches Cargo and Actions weekly.

Report a vulnerability

Do not open a public issue. Use GitHub's private reporting form with the affected version, reproduction steps, and impact. Fixes are provided for the latest released version.

Automated checks reduce risk; they do not prove the absence of vulnerabilities. envit claims no certification.
